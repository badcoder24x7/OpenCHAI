# Container Images

Optionally download container images (Singularity/Apptainer or Docker,
depending on what's configured) for the tools your cluster needs.

Pick a tool, then a version, then check off the specific images you want.
Use **Select all** to grab every image listed for that tool/version
combination at once.

This step is entirely optional — you can click **Finish** without
downloading any container images and add them later by returning to this
wizard.

Downloads run as a background job, same as the Execute step, with live
progress shown below once started.
