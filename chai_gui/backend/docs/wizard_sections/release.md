# Release Notes

This step lists the local **release notes** (`Releases/*.md` on this
machine) — changelogs and upgrade notes for past OpenCHAI releases.
Reading these first, before picking a version to install, helps you
confirm which version actually has the changes or fixes you're looking
for.

This list does **not** require registry access — it only reads files
already present on disk, so it works the same whether or not
authentication succeeded in the previous step.

Selecting a note shows a rendered preview on the right. This step is
informational; you can proceed to the Version step whether or not you
select anything here.

Once you pick a specific OpenCHAI version in the next step, the wizard
will also show any release-specific assets published on the registry
for that exact version (this used to be shown here, but it requires a
version to already be selected, so it now appears alongside the Version
step instead).
